# Throne Tinder

> Swipe to claim a public toilet like it is a flaky date.

The app crowdsources restroom locations and turns each stall into a profile with hygiene photos, price, and a mood. If you skip the stall, it sends a passive-aggressive rejection message to your phone.

## Features
- Stall profiles with cleanliness score and map pin
- Swipe right to reserve a stall
- Passive-aggressive rejection messages
- Weekly toilet reputation badge

## Stack
- React Native
- Firebase
- Mapbox

## Getting started
```
npm install, configure Firebase and Mapbox keys, then run npm start and select iOS or Android.
```
